## What ships

The existing invitation/session remains the Loop login. A signed-in creator connects a Facebook Page and its linked professional Instagram account using Facebook Login. They explicitly choose an eligible Page after consent. No public self-enrollment, account matching by handle or personal Facebook profile analytics is implemented. Direct Instagram Login without a Facebook Page is a different authorization flow and is not part of this connection.

Read-only permissions: `pages_show_list`, `pages_read_engagement`, `read_insights`, `instagram_basic`, `instagram_manage_insights`. No publishing, messaging or advertising permission is requested. Development-mode roles may test; production creator access requires Meta's permission-specific Advanced Access/App Review, even when the business is already verified.

The state is hashed, single-use, bound to the exact session/org/user/profile and expires after ten minutes. Codes are exchanged server-side for long-lived user tokens. Only actual granted permissions are accepted. Pending and persistent tokens use AES-256-GCM with distinct bindings; no token goes to the browser or AWS worker. Account selection re-fetches Pages from Meta and never accepts a submitted Instagram id. A Page may have one active creator owner per tenant. Disconnecting, Meta deauthorization and membership offboarding clear credentials and invalidate in-flight publication. Signed Meta deletion requests erase the imported observations, AI readings, Meta audience observations and connection; unrelated creator data is retained.

Instagram account metrics: views, deduplicated total reach and total interactions over 28 complete UTC days. Facebook Page metrics: media views and post engagements, when available. Up to six recent posts per platform are sampled for lifetime content metrics. Unsupported metrics are individually unavailable, never zero. Content sample metrics are not window totals, daily reach is not summed and repeated rolling windows are never added together. Source/API/platform eligibility limitations remain visible. Stories-specific and audience-demographic collection are not implemented.

The hub shows source timestamps, follower history, sampled top content and sample median views. A separate `creator.analytics.reading` task uses the existing governed OpenAI gateway and domain-reading output validation. It receives numerical observations, timestamps and source references, not names, captions, links, account ids or tokens. It can publish only to the active invoking creator's bound profile, with no organization IAM grants. Persisted readings retain invocation/provider provenance and exact immutable observation ids. Unchanged source fingerprints skip model calls; refused or invalid output produces no substitute AI prose. The existing domain-reading budget class and global spending limits are unchanged; task activation is separate.

## Validation and limits

Provider tests cover exchange shape, exact redirect/state, actual granted scopes, cursor-only pagination on the fixed Graph origin, missing versus zero, authentication/throttle failures and complete-day reach requests. Security tests cover encrypted scope/purpose/key isolation, signed callbacks and state replay. AI tests cover creator-only admission, anonymized context, fingerprint skipping and no canned fallback. Worker tests cover signed fixed-purpose triggers, bounded batches and single-flight execution.

`meta-connection.postgres.test.ts` runs only against a disposable localhost PostgreSQL; Creator Hub CI applies migrations and runs it. It covers session/creator/org isolation, active Page ownership, publication after disconnect, membership offboarding and deletion. No local PostgreSQL or live creator access was available for this implementation run. Check CI and complete the real-account acceptance steps before calling the integration live.

Primary references: Meta Graph API overview, Instagram API with Facebook Login Insights and Page Insights reference at developers.facebook.com; Meta's official Postman Instagram collection at https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api. The browser-accessible official Instagram Account Insights reference (updated June 16, 2026) confirmed views/total_value, reach/total_value, inclusive timestamp ranges and potential data delays of up to 48 hours. The Insights guide (updated October 20, 2026) confirms the Facebook Login scopes and notes additional ads_read/ads_management permissions for some Business Manager-assigned Page roles.
