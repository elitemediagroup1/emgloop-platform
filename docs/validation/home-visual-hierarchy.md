# Home visual hierarchy

The signed-in production homepage was visually inspected at desktop width on October 16. The previous screen repeated the complete AI heading and observations in Your briefing and Headlines, used tall KPI cards dominated by one definition, and placed the viewer's action list far down the page.

The executive Home now presents compact KPIs, one briefing containing the existing ranked priority list, then a separate Headlines tile for business readings, followed by calendar and measured objective signals. Tools keep metrics and source states visible, with long summaries in native details. Recent events are expandable below the tools. Source failures and unavailable states remain visible. Measured objective coverage never becomes a business-wide all-clear. Every model observation and limitation remains available; only the first three observations lead Home, with the remaining observations behind a labelled native disclosure. Daily NEEDS_YOU/AHEAD observations stay with the combined briefing; CHANGED/WATCH model observations appear in Headlines. Existing authorized cross-source Situations retain their evidence and verification in that tile. The full Headlines workspace uses the same component without compact truncation. Rule fallback facts are not presented as model insights. As-of timestamps and newer-metrics disclosure are preserved.

The existing CSS token palette and shared stylesheet supply the presentation. No new package, migration, client component, data query, provider call or production write is introduced. The employee Home retains its own-source boundary and combined calendar/attention card; shared typography and compact tools also apply there.
